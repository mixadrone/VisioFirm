# Перевірка інтерфейсу VisioFirm

Дата: 27 вересня 2026. Playwright CLI, Chromium, http://localhost:8000, проєкт Diodes.

## Виправлено й перевірено

- Меню картки проєкту обрізалося через `overflow: hidden`: звичайний клік Overview перехоплював контейнер Dashboard. Відкрита картка тепер дозволяє меню виходити за її межі. Overview відкривається та закривається; Add Images і Add Classes відкривають відповідні діалоги.
- Settings → Open Canvas → Gallery залишав активною Settings і приховував галерею. Тепер активується Images, галерея видима.
- Завантажені мініатюри полотна мали opacity=0. Обробник враховує вже завантажені зображення; прибрано завантаження всіх мініатюр під час відкриття полотна. Видимі мініатюри відображаються.
- Кнопка Configure AI Pre-annotator оминала ініціалізацію діалогу. Тепер перевірки стану завдання та GPU виконуються, обидва запити повернули HTTP 200.
- JSON → Workflow → Visual втрачав зміни чернетки. Значення stroke_width=7 зберігається між вкладками; некоректний JSON блокує вихід із редактора; повторне натискання JSON не стирає введене. Початкову чернетку відновлено без запису на сервер.
- Вузьку розтягнуту панель Charts виправлено; графіки використовують доступну ширину.
- Прибрано повторне підключення setup.css на Dashboard, оновлено версію адрес CSS: браузер утримував старі стилі після reload. Меню повторно перевірено після звичайного перезавантаження.

## Інші перевірені сценарії

- Dashboard → Diodes; проєкт → Projects → Dashboard; Dashboard → Profile → Dashboard.
- Вкладки Images, Classes, Charts, Models, Export, Settings; Classes → Style Settings.
- Visual / General / Workflow / JSON.
- Вибір YOLO в експорті та перехід до налаштування розбиття.
- Наступне/попереднє зображення, Select Labels, Pan Image, Zoom In/Out, Reset View.
- Відкриття й закриття Create New Project без створення проєкту.
- `node --check` для main.js, viewManagement.js, annotationStyleSettings.js: успішно.
- У завершальних перевірках консолі немає помилок JavaScript. Початковий вхід мав окремий 404 favicon.ico.

## Межі перевірки

Не запускалися видалення, AI-обробка, фінальний експорт або збереження змін анотацій/профілю. Діалоги перевірено без виконання цих операцій. Це перевірка навігації та взаємодій, не повний аудит ML і експортерів. У робочому дереві вже були незакомічені зміни; вони збережені. `git diff --check` виявляє наявні пробіли наприкінці рядків у попередніх змінах.
